## 给孩子介绍历史人物（诗词篇）

阿根廷诗人博尔赫斯曾经说过：任何命运，无论多么漫长复杂，实际上都只反映于一个瞬间。
如果孩子问道历史中的诗人词人的时候，怎么只用一个瞬间就描述清楚呢？

## 李贺
比如：为什么李贺被称为诗鬼，那么李贺的名篇未必有足够的说服力，但是下面这首节选自《苦昼短》中的句子

```
吾不识青天高，黄地厚。
唯见月寒日暖，来煎人寿。
```


全文：

```
飞光飞光，劝尔一杯酒。
吾不识青天高，黄地厚。
唯见月寒日暖，来煎人寿。
食熊则肥，食蛙则瘦。
神君何在？太一安有？
天东有若木，下置衔烛龙。
吾将斩龙足，嚼龙肉，使之朝不得回，夜不得伏。
自然老者不死，少者不哭。
何为服黄金、吞白玉？
谁似任公子，云中骑碧驴？
刘彻茂陵多滞骨，嬴政梓棺费鲍鱼。
```

翻译
```
飞逝的时光啊，请饮我一杯酒。
我不知道苍天多高、大地多厚，
只看见月冷日暖，岁岁流转，慢慢消磨人的寿命。
人吃珍美的熊肉就丰腴，吃粗陋蛙食就瘦弱。
神仙在哪里？天神太一又何曾存在？
东方有神树若木，树下有衔烛神龙驾驭日月。
我要砍断龙足、吃掉龙肉，让它不能朝升夜落。
这样老人就不会衰老死去，少年也不必悲愁。
何必服食黄金白玉以求长生？
哪里有任公子那样得道仙人，骑着碧驴遨游云天？
汉武帝茂陵里只剩枯骨，秦始皇棺椁只能用鲍鱼掩盖尸臭。
```

诗鬼李贺炼字一绝一个**煎**字是全诗诗眼。日月冷暖本是自然常态，李贺却写出一种持续、缓慢、无处可逃的消耗感，把无形的时间变成熬煮生命的烈火，凄切冷峻。

典型 “诗鬼” 手笔，奇想激烈，甚至幻想斩杀驾日的烛龙来停止时间、永免生死，狂愤又悲凉

# 陶渊明
为什么一提隐士，最先想到陶渊明，一句“采菊东篱下，悠然见南山”就能定格他。
名篇节选《饮酒·其五》
```
结庐在人境，而无车马喧。
问君何能尔？心远地自偏。
采菊东篱下，悠然见南山。
山气日夕佳，飞鸟相与还。
此中有真意，欲辨已忘言。
```
翻译
```
我住在人群聚居的地方，却听不到车马的喧闹。
要问我怎么能做到这样？只要内心清净远离名利，居所自然就僻静。
在东边篱笆下采摘菊花，不经意间抬头，恰好望见远处的南山。
傍晚山间云雾柔和，飞鸟结伴归巢。
这情景里藏着人生真正的滋味，想说清楚，却找不到合适的言语。
```
陶渊明的妙处藏在**悠然**二字。不是刻意躲开世人、躲进深山，就算身在人间烟火，内心也能自在安宁。不追逐功名，安于朴素日常，在一朵菊、一座山里寻得心安，是中国人心中最温柔的理想模样。

# 李白（诗仙）
为什么李白叫诗仙，“安能摧眉折腰事权贵，使我不得开心颜”最能代表他骨子里的模样。
名篇节选《梦游天姥吟留别》
```
海客谈瀛洲，烟涛微茫信难求；
越人语天姥，云霞明灭或可睹。
天姥连天向天横，势拔五岳掩赤城。
天台四万八千丈，对此欲倒东南倾。
……
安能摧眉折腰事权贵，使我不得开心颜！
```
翻译
```
航海的人说起瀛洲仙山，烟波渺茫实在难以寻觅；
越地的人谈起天姥山，云霞忽明忽暗，或许能够看见。
天姥山高耸连着天际，山势超过五岳，遮蔽赤城山。
天台山就算高达四万八千丈，面对着它，也好像要向东南倾斜拜倒一样。
……
怎么能够低头弯腰，去侍奉有权势的人，让我自己心中郁郁不欢！
```
李白的底色是**不肯折腰**。他才华盖世，本可以依附权贵换取前程，却不愿委屈本心。他的文字像乘风的仙人，自由狂放，永远遵从自己的心意，不向世俗低头。

# 杜甫（诗圣）
为什么杜甫被尊为诗圣，不是豪迈的句子，而是“安得广厦千万间，大庇天下寒士俱欢颜”。
名篇节选《茅屋为秋风所破歌》
```
俄顷风定云墨色，秋天漠漠向昏黑。
布衾多年冷似铁，娇儿恶卧踏里裂。
床头屋漏无干处，雨脚如麻未断绝。
自经丧乱少睡眠，长夜沾湿何由彻！
安得广厦千万间，大庇天下寒士俱欢颜！风雨不动安如山。
呜呼！何时眼前突兀见此屋，吾庐独破受冻死亦足！
```
翻译
```
一会儿大风停下，乌云浓黑，秋日天色渐渐昏暗。
盖了多年的被子冷硬得像铁块，孩子睡不安稳，把被里都蹬破了。
屋顶漏雨，屋子里没有一块干燥地方，雨水像麻线一样不停落下。
自从战乱之后我就很少安睡，漫漫长夜，到处潮湿，怎么熬到天亮！
怎么才能拥有千万间宽大房屋，庇护天下穷苦读书人，让他们都展露笑颜！任凭风吹雨打，安稳如山。
唉！什么时候眼前能突然出现这样的屋子，就算只有我的茅屋破败，我受冻死去也心甘情愿！
```
杜甫动人的地方，在于**推己及人**。自己茅屋漏雨、饥寒交迫，心里惦记的却还是天下受苦的普通人。一生历经战乱苦难，始终心怀苍生，文字里装着人间疾苦，厚重慈悲。

# 苏轼（东坡）
为什么苏轼千百年来人人喜爱，一句“竹杖芒鞋轻胜马，谁怕？一蓑烟雨任平生”就能概括。
名篇《定风波·莫听穿林打叶声》
```
莫听穿林打叶声，何妨吟啸且徐行。
竹杖芒鞋轻胜马，谁怕？一蓑烟雨任平生。
料峭春风吹酒醒，微冷，山头斜照却相迎。
回首向来萧瑟处，归去，也无风雨也无晴。
```
翻译
```
不必去听雨点穿过树林敲打树叶的声响，不妨一边放声吟诗，一边慢慢往前走。
拄着竹杖、穿着草鞋，比骑马还要轻快，有什么可怕的？一身蓑衣，任凭一生风雨。
微凉的春风吹醒酒意，身上微微发冷，山头落日的光芒迎面照来。
回头望向刚才淋雨的地方，转身离去，无所谓风雨，也无所谓晴天。
```
苏轼的核心是**任平生**。他一辈子反复被贬、颠沛流离，遇到突如其来的风雨，不慌乱、不抱怨。顺境不骄傲，逆境不消沉，接纳人生起落，平和从容，是中国人最向往的豁达。

# 辛弃疾（词中之龙）
为什么辛弃疾和别的文人不一样，“醉里挑灯看剑，梦回吹角连营”，藏着英雄的遗憾。
名篇《破阵子·为陈同甫赋壮词以寄之》
```
醉里挑灯看剑，梦回吹角连营。
八百里分麾下炙，五十弦翻塞外声，沙场秋点兵。
马作的卢飞快，弓如霹雳弦惊。
了却君王天下事，赢得生前身后名。可怜白发生！
```
翻译
```
醉酒之后，挑亮灯火端详宝剑，梦里回到军营，耳边响起连绵的号角。
把烤牛肉分给部下享用，乐器奏响边塞雄壮的战歌，秋日战场上检阅军队。
战马像的卢一样飞驰，弓弦拉动，响声如同惊雷。
一心想要完成收复国土的大业，赢得生前身后的美名。可惜，头发早已白了，壮志难酬！
```
辛弃疾最动人的是**英雄梦碎**。他不是只会写字的书生，本是能上阵杀敌的勇士，可朝廷偏安，没有机会奔赴战场。只能在醉酒与梦里重温沙场豪情，壮志未酬的悲壮，让他的词自带金戈铁马的力量。

# 李清照（千古第一才女）
为什么李清照与众不同，一句“生当作人杰，死亦为鬼雄”，跳出了柔弱闺阁女子的印象。
名篇《夏日绝句》
```
生当作人杰，死亦为鬼雄。
至今思项羽，不肯过江东。
```
翻译
```
活着就要做人中的豪杰，死去也要做鬼里的英雄。
直到今天我依然敬佩项羽，兵败之后，不肯逃回江东苟且求生。
```
李清照的力量在于**风骨**。早年她写花草、写闲愁，温婉细腻；可国破家亡之后，她写下这样铿锵的诗句。一个女子，在乱世里心怀家国，推崇气节，刚硬豪迈，不输男儿。

# 陈子昂（诗骨）
为什么短短四句流传千年，“念天地之悠悠，独怆然而涕下”，写尽人在天地间的孤独。
名篇《登幽州台歌》
```
前不见古人，后不见来者。
念天地之悠悠，独怆然而涕下。
```
翻译
```
往前，见不到古时礼贤的明君；往后，等不到后世赏识人才的贤主。
想到这无穷无尽、苍茫辽阔的天地，不由得满心悲伤，落下眼泪。
```
陈子昂的核心是**苍茫**。他登高远眺，个人的失意和宏大的时空撞在一起。世间无穷无尽，可懂自己的人无处寻觅，这是所有人都能共情的孤独，苍凉厚重，被称作“诗骨”。

# 李商隐
为什么李商隐的诗总带着朦胧怅惘，“此情可待成追忆？只是当时已惘然”最能概括。
名篇节选《锦瑟》
```
锦瑟无端五十弦，一弦一柱思华年。
庄生晓梦迷蝴蝶，望帝春心托杜鹃。
沧海月明珠有泪，蓝田日暖玉生烟。
此情可待成追忆？只是当时已惘然。
```
翻译
```
精美的瑟为什么偏偏有五十根琴弦？每一弦每一柱，都勾起对青春往事的怀念。
曾经像庄周梦醒，分不清自己是蝴蝶还是本人；又像望帝，把心事托付给声声啼鸣的杜鹃。
明月照在沧海，珍珠仿佛含泪；暖阳笼罩蓝田，美玉似有烟气朦胧。
这份情感哪里要等到回忆时才怅然？其实在当时，心里就已经一片迷茫。
```
李商隐的妙处在于**惘然**。很多心事，当下就说不清道不明，等到岁月流逝再回头回味，更加朦胧伤感。文字优美含蓄，说不清是爱情、身世感慨还是人生遗憾，朦胧幽深，耐人反复品味。

# 王维（诗佛）
为什么王维被称作诗佛，一句**行到水穷处，坐看云起时**最能定格他。
名篇《终南别业》
```
中岁颇好道，晚家南山陲。
兴来每独往，胜事空自知。
行到水穷处，坐看云起时。
偶然值林叟，谈笑无还期。
```
翻译
```
中年之后我倾心于佛道，晚年安家在终南山边。
兴致来了常常独自出游，其中美好的意趣只有自己体会。
走到溪水的尽头，索性静静坐下，看云朵悠悠升起。
偶然遇见山中老者，和他闲谈，常常忘了归家的时间。
```
王维的内核是**随缘**。不是刻意避世苦修，而是顺着本心行走。路走到尽头不必焦虑，原地安住，自有新的风景。山水之间放下执念，安静从容，字里藏着清淡空灵的禅意。

# 陆游
为什么陆游是最执着的爱国诗人，一句**夜阑卧听风吹雨，铁马冰河入梦来**最动人。
名篇《十一月四日风雨大作·其二》
```
僵卧孤村不自哀，尚思为国戍轮台。
夜阑卧听风吹雨，铁马冰河入梦来。
```
翻译
```
我衰老困居在偏僻的村落里，却并不为自己处境哀伤，心里还想着为国戍守边疆。
深夜躺在床上听外面风雨呼啸，梦里仿佛看见骑兵踏过冰封的江河奔赴战场。
```
陆游最珍贵的是**至死不忘**。一生屡遭打击、年老闲居，现实里再也没有上阵机会，可风雨声一响，梦里依旧是家国沙场。满腔报国之心，到老也不曾冷却。

# 刘禹锡（诗豪）
为什么刘禹锡被叫做诗豪，**沉舟侧畔千帆过，病树前头万木春**最能体现他。
名篇节选《酬乐天扬州初逢席上见赠》
```
巴山楚水凄凉地，二十三年弃置身。
怀旧空吟闻笛赋，到乡翻似烂柯人。
沉舟侧畔千帆过，病树前头万木春。
今日听君歌一曲，暂凭杯酒长精神。
```
翻译
```
被贬到巴山楚水这样荒凉偏远之地，二十三年一直被闲置放逐。
怀念旧友只能空自吟诵怀旧诗篇，重回故乡，恍如隔世。
沉船旁边，还有无数船只扬帆驶过；枯树前面，万千林木蓬勃逢春。
今天听到你为我吟唱诗篇，暂且借着这杯酒，重新振作精神。
```
刘禹锡的风骨在于**不颓**。长期被贬、命运坎坷，却不沉溺伤痛。他看见衰败之外永远有新生，逆境之中依然昂扬豁达，风骨刚健，所以人称“诗豪”。

# 文天祥
为什么文天祥是千古气节的代表，**人生自古谁无死？留取丹心照汗青**足以流传万世。
名篇《过零丁洋》
```
辛苦遭逢起一经，干戈寥落四周星。
山河破碎风飘絮，身世浮沉雨打萍。
惶恐滩头说惶恐，零丁洋里叹零丁。
人生自古谁无死？留取丹心照汗青。
```
翻译
```
我早年凭借经书入仕，历经艰辛；战火四起，已经熬过四年。
国家山河破碎，如同风中飘飞的柳絮；我个人身世起伏，好似雨中漂泊的浮萍。
曾经在惶恐滩感慨危难，如今在零丁洋慨叹孤苦无依。
自古以来人终有一死，我愿留存赤诚忠心，永远映照在史册之中。
```
文天祥的底色是**丹心**。国破被俘，敌人以高官厚禄劝降，他宁死不从。生死关头，不在意肉身存亡，只求守住内心的大义与气节。

# 林逋
为什么提到梅花隐士就想到林逋，**疏影横斜水清浅，暗香浮动月黄昏**已成绝唱。
名篇《山园小梅·其一》
```
众芳摇落独暄妍，占尽风情向小园。
疏影横斜水清浅，暗香浮动月黄昏。
霜禽欲下先偷眼，粉蝶如知合断魂。
幸有微吟可相狎，不须檀板共金樽。
```
翻译
```
百花凋零之后，唯有梅花明媚盛开，独自占尽小园风光。
稀疏的花枝影子斜映在清浅水面，淡淡的幽香，在朦胧月色里轻轻飘散。
寒鸟想要落下，先悄悄偷看梅花；粉蝶若是知晓这份美好，定会心神沉醉。
幸而我可以低声吟诗与梅花相伴，不需要乐曲美酒来烘托热闹。
```
林逋的意境是**孤洁**。他终身不娶、隐居孤山，以梅为妻、以鹤为子。不追逐世俗热闹，独爱梅花清雅淡远的姿态，清冷高洁，不染尘俗。

# 贺铸（贺梅子）
为什么贺铸一句词就留下外号，**一川烟草，满城风絮，梅子黄时雨**最能写尽无边愁绪。
名篇《青玉案·凌波不过横塘路》
```
凌波不过横塘路，但目送、芳尘去。
锦瑟华年谁与度？月桥花院，琐窗朱户，只有春知处。
飞云冉冉蘅皋暮，彩笔新题断肠句。
试问闲愁都几许？
一川烟草，满城风絮，梅子黄时雨。
```
翻译
```
佳人步履轻盈，却不肯走到横塘这边，我只能远远目送她远去。
这样美好的青春年华，她将和谁一同度过？月夜小桥、繁花庭院，雕花窗棂的屋舍，大概只有春风知道她的居所。
云朵缓缓飘过长满香草的水边，天色渐晚，我提笔写下令人惆怅的诗句。
若要问我心中的闲愁究竟有多少？
就像遍地连绵的青草，满城纷飞的柳絮，还有黄梅时节连绵不绝的细雨。
```
贺铸的妙处在于**化虚为实**。看不见摸不着的淡淡愁绪，化作漫川青草、漫天飞絮、连绵梅雨，无边无际，挥之不去，后人直接称他“贺梅子”。

# 张若虚
为什么《春江花月夜》孤篇压全唐，**江畔何人初见月？江月何年初照人**一问穿越千古。
名篇节选《春江花月夜》
```
春江潮水连海平，海上明月共潮生。
滟滟随波千万里，何处春江无月明！
……
江畔何人初见月？江月何年初照人？
人生代代无穷已，江月年年望相似。
不知江月待何人，但见长江送流水。
```
翻译
```
春天江水涨潮，和大海连成一片，一轮明月随着潮水缓缓升起。
月光波光荡漾，洒向万里江河，哪里的春江不沐浴月色！
……
是谁最早在江边看见这轮明月？这江上的月亮，又是在哪一年最初照耀人间？
人类一代又一代绵延不绝，江上明月年复一年却总是相似。
不知道江月究竟在等待谁，只看见长江江水不停向东奔流。
```
张若虚的力量是**宇宙之思**。不止写春江月夜的美景，抬头望月时，忽然追问人与时空的关系。个体生命短暂，而天地永恒，温柔又苍茫，所以这一篇被评价孤篇盖全唐。

# 王昌龄（七绝圣手）
为什么王昌龄的诗干净又有风骨，**洛阳亲友如相问，一片冰心在玉壶**最适合讲给孩子。
名篇《芙蓉楼送辛渐·其一》
```
寒雨连江夜入吴，平明送客楚山孤。
洛阳亲友如相问，一片冰心在玉壶。
```
翻译
```
冷雨洒满江水，连夜笼罩吴地；清晨送别友人，只留下楚山孤零零矗立。
如果洛阳的亲人朋友问起我的近况，请告诉他们：我的内心，像盛在玉壶里的冰一样澄澈干净。
```
王昌龄的核心是**澄澈**。身处官场风波，不向别人辩解委屈，只用冰心玉壶自喻。无论外界如何评价，坚守内心纯粹高洁，干净坚定。

# 晏殊
为什么晏殊能写出最动人的淡淡怅惘，**无可奈何花落去，似曾相识燕归来**是他的标志。
名篇《浣溪沙》
```
一曲新词酒一杯，去年天气旧亭台。夕阳西下几时回？
无可奈何花落去，似曾相识燕归来。小园香径独徘徊。
```
翻译
```
填一首新词，饮一杯薄酒，还是去年一样的天气、旧时的亭台。夕阳向西沉落，什么时候才能再次回来？
花儿凋零，人力无法挽留；燕子归来，好像曾经见过。我独自在飘着花香的小院小路上来回踱步。
```
晏殊的内核是**淡愁**。他身居高位，一生安稳富贵，没有颠沛流离的大悲苦，却敏锐捕捉时光流逝的伤感。不是痛哭，只是安静体会美好事物留不住的遗憾，温柔克制，余味悠长。

# 元好问
为什么一句词写尽世间至情，**问世间，情是何物，直教生死相许**流传至今。
名篇《摸鱼儿·雁丘词》
```
乙丑岁赴试并州，道逢捕雁者云：“今旦获一雁，杀之矣。其脱网者悲鸣不能去，竟自投于地而死。”予因买得之，葬之汾水之上，垒石为识，号曰雁丘。时同行者多为赋诗，予亦有《雁丘词》。
问世间，情是何物，直教生死相许？
天南地北双飞客，老翅几回寒暑。
欢乐趣，离别苦，就中更有痴儿女。
君应有语：渺万里层云，千山暮雪，只影向谁去？
```
翻译
```
试问人世间，感情究竟是什么东西？竟然值得用生命去相守。
它们本是天南地北一同飞翔的伴侣，年年寒暑相伴，一起飞过漫长岁月。
共享过欢聚的快乐，也承受分离的苦楚，世间痴情的人，也如同这大雁一般。
你心里一定明白：辽阔万里云层、千山暮色落雪，只剩孤身，再去找谁相伴？
```
元好问的震撼在于**至痴**。由大雁殉情而起笔，不局限男女情爱，写一种愿意以生死兑现的真挚羁绊。苍茫厚重，质朴又直击人心。

# 贾岛（苦吟诗人）
为什么贾岛被称作苦吟代表，**鸟宿池边树，僧敲月下门**最能体现他。
名篇《题李凝幽居》
```
闲居少邻并，草径入荒园。
鸟宿池边树，僧敲月下门。
过桥分野色，移石动云根。
暂去还来此，幽期不负言。
```
翻译
```
清幽居所很少有邻居，长满野草的小路通向荒芜的小院。
鸟儿栖息在池塘边的树上，夜深月光下，僧人轻轻叩响院门。
走过小桥，原野风光层次分明；山石移动，仿佛牵动了扎根山间的云气。
我暂且离开，日后还会再来此地，绝不辜负归隐的约定。
```
贾岛的特点是**推敲**。他写诗字字斟酌、反复打磨，“推”和“敲”的故事流传千古。文字清冷安静，偏爱荒寂幽微的景色，一字一句细细雕琢，是典型苦吟之风。

# 许浑
为什么乱世的预感藏在一句诗里，**溪云初起日沉阁，山雨欲来风满楼**。
名篇《咸阳城东楼》
```
一上高城万里愁，蒹葭杨柳似汀洲。
溪云初起日沉阁，山雨欲来风满楼。
鸟下绿芜秦苑夕，蝉鸣黄叶汉宫秋。
行人莫问当年事，故国东来渭水流。
```
翻译
```
一登上高高的城楼，无边愁绪涌上心头，芦苇杨柳丛生，好似家乡水边沙洲。
溪上云雾刚刚升起，夕阳隐入楼阁之后；山雨将要来临，狂风灌满整座城楼。
暮色里飞鸟落入荒草丛生的秦汉旧苑，黄叶间秋蝉声声哀鸣。
来往过客不必追问前朝兴亡旧事，只有渭水依旧从东方缓缓流淌。
```
许浑的力量是**预感**。大唐渐渐走向衰落，他登楼远眺，风声里提前感受到时代动荡。一句山雨欲来，把风雨将至的压抑、王朝末世的苍茫写得极具画面感。

# 曹松
为什么短短一句冷得刺骨，**凭君莫话封侯事，一将功成万骨枯**。
名篇《己亥岁二首·其一》
```
泽国江山入战图，生民何计乐樵苏。
凭君莫话封侯事，一将功成万骨枯。
```
翻译
```
江河遍布的国土全都划入作战版图，普通百姓连砍柴度日、安稳生存都难以实现。
请你不要再谈论建功封侯的荣耀，一位大将功成名就的背后，是无数士兵枯骨。
```
曹松的底色是**冷峻**。世人歌颂战功、崇拜名将，他却看见荣耀之下无数普通人的牺牲。没有激烈呐喊，一句平实的话撕开战争残酷的真相，沉重警醒。

# 崔颢
为什么李白见了都搁笔，**日暮乡关何处是？烟波江上使人愁**。
名篇《黄鹤楼》
```
昔人已乘黄鹤去，此地空余黄鹤楼。
黄鹤一去不复返，白云千载空悠悠。
晴川历历汉阳树，芳草萋萋鹦鹉洲。
日暮乡关何处是？烟波江上使人愁。
```
翻译
```
古时仙人早已乘着黄鹤飞走，这里只留下一座黄鹤楼。
黄鹤离去再也没有回来，千百年来只有白云自在飘荡。
晴朗的江对岸，汉阳的树木清晰分明，鹦鹉洲上青草繁茂。
天色黄昏，我的家乡究竟在哪里？江上朦胧烟波，勾起无尽乡愁。
```
崔颢动人之处是**苍茫乡愁**。登楼怀古，仙人远去、时光悠悠，最后落到普通人最朴素的思乡之情。情景浑然一体，相传李白登临黄鹤楼，读完此诗感叹眼前有景道不得，不再提笔作诗。

# 王之涣
为什么寥寥两句成为盛唐气象，**欲穷千里目，更上一层楼**。
名篇《登鹳雀楼》
```
白日依山尽，黄河入海流。
欲穷千里目，更上一层楼。
```
翻译
```
夕阳靠着远山慢慢落下，奔腾黄河向着大海滚滚东流。
想要望尽千里辽阔风光，就要再登上更高的一层楼台。
```
王之涣的内核是**向上**。壮阔山河尽收眼底，不止写景，藏着开阔的志向。视野有限的时候，提升自己，才能看见更远的世界，简洁大气，非常适合讲给孩子。

# 柳宗元
为什么柳宗元的文字自带清寂孤冷，**孤舟蓑笠翁，独钓寒江雪**最是传神。
名篇《江雪》
```
千山鸟飞绝，万径人踪灭。
孤舟蓑笠翁，独钓寒江雪。
```
翻译
```
连绵群山之中，看不见飞鸟的影子；万千小路之上，没有行人的踪迹。
一叶孤舟里，一位身披蓑衣、头戴斗笠的老翁，独自在漫天风雪的江上垂钓。
```
柳宗元的内核是**孤守**。他遭贬之后身处蛮荒之地，处境孤寂苦寒。天地一片苍茫死寂，老翁不是在钓鱼，是在严寒绝境里守住自己不屈的本心。清冷极简，风骨藏于寂静之中。

# 秦观（秦少游）
为什么秦观的愁细腻柔婉，**两情若是久长时，又岂在朝朝暮暮**跳出了小儿女的执念。
名篇《鹊桥仙·纤云弄巧》
```
纤云弄巧，飞星传恨，银汉迢迢暗度。
金风玉露一相逢，便胜却人间无数。
柔情似水，佳期如梦，忍顾鹊桥归路。
两情若是久长时，又岂在朝朝暮暮。
```
翻译
```
轻薄的云彩变幻出精巧模样，流星传递着相思的怅憾，牛郎织女悄悄渡过遥远银河相会。
在秋风白露的美好时节相逢一次，就胜过尘世间千千万万朝夕相伴。
温柔情意如同流水，短暂相会恍如梦境，怎忍心回望鹊桥分别的归路。
倘若两人的感情能够长久忠贞，又何必一定要日夜相守在一起。
```
秦观的妙处是**通透深情**。不沉溺离别哀怨，升华了爱情的境界。真正珍贵的情意，不在于朝夕厮守，而在于长久的相知坚守，婉约却格局开阔。

# 岳飞
为什么岳飞是民族英雄的代表，**三十功名尘与土，八千里路云和月**写尽壮志征途。
名篇《满江红·写怀》
```
怒发冲冠，凭栏处、潇潇雨歇。
抬望眼、仰天长啸，壮怀激烈。
三十功名尘与土，八千里路云和月。
莫等闲、白了少年头，空悲切！
靖康耻，犹未雪。臣子恨，何时灭！
驾长车，踏破贺兰山缺。
壮志饥餐胡虏肉，笑谈渴饮匈奴血。
待从头、收拾旧山河，朝天阙。
```
翻译
```
悲愤得头发竖起顶起冠帽，倚靠栏杆，骤雨刚刚停歇。
抬头远望，仰天长声呼啸，胸中激荡着报国壮志。
三十年来建立的功名，不过如同尘土；转战八千里，一路伴着流云明月。
千万不要虚度年华，等到青丝变成白发，只能白白伤心悔恨！
靖康年间的国耻，还没有洗雪；作为臣子的恨意，何时才能消弭！
我要驾着战车，踏破贺兰山的关隘。
满怀壮志，饿了就吃敌寇的肉，谈笑间渴了就饮敌人的鲜血。
等到重新收复旧日山河，再凯旋朝拜皇宫。
```
岳飞的底色是**报国壮志**。一生以收复故土为己任，词句慷慨激昂，既有征战的艰辛，又有争分夺秒、不愿虚度青春的警醒，正气凛然。

# 张继
为什么一次夜泊的偶然愁思流传千年，**姑苏城外寒山寺，夜半钟声到客船**。
名篇《枫桥夜泊》
```
月落乌啼霜满天，江枫渔火对愁眠。
姑苏城外寒山寺，夜半钟声到客船。
```
翻译
```
月亮西沉，乌鸦啼叫，寒霜布满夜空；江边枫树、点点渔火，伴着满怀愁绪难以入眠。
苏州城外的寒山寺，半夜里敲响的钟声，悠悠飘到我漂泊的客船之上。
```
张继的动人之处是**客愁**。诗人旅途漂泊，深夜无眠。钟声本是寻常声响，却撞在了游子孤寂的心上。没有激烈的情绪，淡淡的羁旅惆怅，安静又绵长。

# 高适（高常侍）
为什么盛唐边塞诗雄浑慷慨，**莫愁前路无知己，天下谁人不识君**。
名篇《别董大二首·其一》
```
千里黄云白日曛，北风吹雁雪纷纷。
莫愁前路无知己，天下谁人不识君。
```
翻译
```
漫天黄沙绵延千里，日光昏黄暗淡；北风呼啸，大雁南飞，大雪纷纷扬扬。
不必担心前方路途上遇不到知己，普天之下，有谁不认识你这样的英才。
```
高适的内核是**豪迈宽慰**。送别诗大多伤感不舍，他却一扫离愁，用开阔有力的话语鼓励友人。在困顿离别之时，给予人十足的信心与底气，大气爽朗。

# 李煜（南唐后主）
为什么亡国之君的词句直击人心，**问君能有几多愁？恰似一江春水向东流**。
名篇《虞美人》
```
春花秋月何时了？往事知多少。
小楼昨夜又东风，故国不堪回首月明中。
雕栏玉砌应犹在，只是朱颜改。
问君能有几多愁？恰似一江春水向东流。
```
翻译
```
年年春来花开、秋来月圆，这样的日子什么时候才能结束？多少故国往事涌上心头。
昨夜小楼又吹起春风，明月之下，实在不忍心回想已经灭亡的故土。
昔日皇宫雕花栏杆、玉石台阶应该还在，只是当年的人早已容颜衰老、物是人非。
如果要问心中到底有多少哀愁？就像奔腾不息的一江春水，滚滚向东不停流淌。
```
李煜的力量是**无尽之愁**。从一国之君沦为阶下囚，昔日繁华尽数消散。把看不见的亡国悲痛，化作滔滔不绝的江水，哀痛绵长，千古一绝。
