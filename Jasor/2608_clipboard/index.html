下载 clipboard_backend.py
  1. 安装依赖：pip install Pillow
  2. 推荐常驻唤醒器：pythonw clipboard_backend.py --launcher（很轻，开机可挂着）
  3. 本页连接后会自动拉起 server；关闭页面约 90 秒无请求后 server 自动退出
  4. 也可直接运行：python clipboard_backend.py（同样支持空闲自动退出）
