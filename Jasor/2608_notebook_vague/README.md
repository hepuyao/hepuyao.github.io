## Local helper

1. Download `note_backend.py` and `requirements.txt` from the page
2. `pip3 install -r requirements.txt`
3. `python3 note_backend.py`
4. Refresh the page → badge shows **本地：已连接**
5. If still offline: allow **Local Network** access for this site in the browser, then click **重试连接**

If you see `Address already in use`, the helper is already running — do not start a second copy.

Data: `~/.culinux/notebook_sync.json`
